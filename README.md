**¿Tiene alguna incidencia definir en la base de datos los campos de fecha como tipo DATE o como varchar al momento de enviar la peticion?**
Sí, ya que si los campos son definidos como tipo varchar, se podria ingresar cualquier valor a la base de datos
sin importar que estos sean de tipo date o no, además no tendría las funcionalidades que tiene el tipo date.
